tpcWebGUI is deployed as {{ include "tpcwebgui.fullname" . }} (namespace {{ .Release.Namespace }}).

Access token:
  kubectl get secret -n {{ .Release.Namespace }} {{ include "tpcwebgui.tokenSecret" . }} -o jsonpath='{.data.{{ .Values.accessToken.secretKey }}}' | base64 -d; echo
{{- if .Values.ingress.enabled }}

Open (once per browser; the token is then kept in a cookie):
{{- $prefix := include "tpcwebgui.urlPrefix" . }}
{{- range .Values.ingress.hosts }}
  https://{{ . }}{{ $prefix }}/?token=<token>
{{- end }}
  The URL must end with "/" before "?token=".
{{- else }}

Without ingress:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "tpcwebgui.fullname" . }} 8080:{{ .Values.service.port }}
  http://localhost:8080{{ include "tpcwebgui.urlPrefix" . }}/?token=<token>
{{- end }}

Logs / output files:
  kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "tpcwebgui.fullname" . }}
  kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "tpcwebgui.fullname" . }} -- ls -l /work
